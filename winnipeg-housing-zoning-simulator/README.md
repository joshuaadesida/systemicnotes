# Winnipeg Housing & Zoning Reform Simulator

An independent SystemicNotes project by Joshua Adesida. The tool models ten-year redevelopment scenarios across Winnipeg and pairs them with observed census and permit data.

[Open the live simulator](https://joshuaadesida.github.io/systemicnotes/winnipeg-housing-zoning-simulator/)

The publication includes the project’s methods, original data links and a downloadable source package.
